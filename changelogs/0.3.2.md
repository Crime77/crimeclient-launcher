## Launcher Changelog v0.3.2

### Fixes
- **Linux Window** - The window no longer flickers or shows the desktop through parts of it on some Linux setups (NVIDIA, Wayland). It is opaque now, and WebKit's DMA-BUF renderer is off unless you set WEBKIT_DISABLE_DMABUF_RENDERER yourself
- **New Website Address** - The website and download links, also on the Discord status, now point to crimeclient.duckdns.org

### Improvements
- **NixOS** - `nix run github:Crime77/crimeclient-launcher` starts the launcher on NixOS. Started that way, it leaves updates to Nix
