## 📋 Launcher Changelog v0.2.2

### ✨ New Features
- **CrimeClient Rust (Beta)** - The Rust edition of CrimeClient is out as its own profile "CrimeClient Rust (Beta)". It runs on Horizon, a Minecraft client written in Rust, with the HUD, cosmetics, voice chat, minimap, emotes, chat comfort and the Photon shader built in
- **Wardrobe For Rust Profiles** - What you put on in the shop's wardrobe also goes to your Rust profiles, so you look the same in both editions
- **Photon Shader Page** - Rust profiles get a "Photon shader" page: switch Photon on or off, pick a quality level and change every option of the pack, sorted like the pack's own screens. "Take over from Java profile" copies the Photon settings you made with Iris

### ⚡ Improvements
- **Faster Rust Updates** - An update that keeps the same Horizon version reuses the prepared game files instead of preparing them again
