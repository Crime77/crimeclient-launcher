## Launcher Changelog v0.4.0

### New
- **CrimeClient Insider** - Accounts with Insider access get the profile "CrimeClient Insider" with its own pack. The launcher asks for it at start and after every account change, so it shows up as soon as you are added
- **Protected Insider Download** - The Insider jar is loaded with your account's CrimeClient sign-in and checked by SHA-256; a wrong file is deleted and loaded again

### Improvements
- **Access Check at Launch** - An account without Insider access cannot start the Insider profile, not even from a shortcut. Switch to an account with access or start the normal CrimeClient profile
- **Accounts** - The answer for each account is kept, so the profile stays in place while you are offline
