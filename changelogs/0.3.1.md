## Launcher Changelog v0.3.1

### New Features
- **Settings Per Account** - Mod configs, game settings, key binds and the server list are now the same in every profile and are kept per Microsoft account. Switch the account and the next launch brings that account's settings; a new account starts with a copy of the one you played with last. The first launch of each profile moves its configs into the shared copy; files that were already there stay in the profile as a backup. You find it as "Konto-Einstellungen" on the Sync Packs page, where you can switch it off
