## 📋 Launcher Changelog v0.2.1

### ✨ New Features
- **CraftAttack On The Start Page** - A card shows whether the server is online, who is playing, the message of the day and your ping, and joins with one click
- **One Discord Status** - Launcher and game share one Discord activity of the CrimeClient app instead of showing two
- **Automatic Updates** - New launcher versions install themselves from now on. Every update is signed and checked before it runs
- **Groundwork For CrimeClient Rust** - The launcher can start the coming Rust edition of CrimeClient with your normal sign-in. It shows up once it is released

### 🐛 Bug Fixes
- **Stop Never Hits Another Program** - Windows reuses process numbers. After a restart the launcher could list an unrelated program under an old game's number as a running instance, and Stop would have closed it. An instance now only counts when it really is the game the launcher started

### 🧹 Chores
- **NoRisk Leftovers Removed** - Friends, chat, notifications, the capes page, ads, statistics and other parts of the NoRisk launcher that did nothing for CrimeClient are gone
